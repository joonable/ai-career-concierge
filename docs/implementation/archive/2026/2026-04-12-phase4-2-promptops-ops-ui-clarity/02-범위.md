## 범위

- `/internal/prompts` 상단 정보구조를 운영자용 섹션 중심으로 재설계
- 현재 프롬프트 상태, 실험/비교 추적, 후속 액션 추적, 최신 iteration 해석, 운영 참고 자료 영역으로 재구성
- local canonical fixture인 `src/agent/evals/fixtures/job_eval_gold.json` 기반 golden dataset snapshot 로딩
- 운영 패널 내 golden dataset 목록 + 상세 요약 read-only 노출
- 결과/실험/평가 지표와 golden dataset 기준 간의 연결 설명 추가
- compare / review queue / backlog / latest iteration 링크의 라벨과 설명을 한국어로 정리
- agent loop 실행 버튼이 어떤 동작을 수행하는지 문맥 안에서 설명
