## 범위

### 버그 1: FastAPI 포트 고정 8000 (worktree간 충돌)
- **파일**: `scripts/worktree_common.sh`
- **현상**: `api_port`를 `.env.development`에서 읽되, 없으면 8000 고정 → 동시 실행 시 충돌
- **수정**: agent kind별 FastAPI 포트 베이스 정의 및 `assign_dev_port`와 동일한 방식으로 배정
  - `codex=8100`, `claude=8200`, `gemini=8300`, `integration=8400`
- `bootstrap_web_env_for_worktree` 함수에서 api_port를 배정된 값으로 교체
- `.env.development.local`에 `FASTAPI_PORT=${api_port}` 출력 추가

### 버그 2: `api_base_url` 구성 버그
- **파일**: `scripts/worktree_common.sh`
- **현상**: `${web_origin%:*}:${api_port}` — `WEB_ORIGIN=http://localhost`이면 `http:8000`이 됨
- **수정**: `api_base_url="http://localhost:${api_port}"` 로 단순화 (worktree는 항상 localhost 기준)
- `WEB_ORIGIN` 기반 파싱 로직 제거

### 버그 3: `.claude/launch.json` 구식
- **파일**: `.claude/launch.json`
- **현상**: `port: 3000`, `port: 8000` 하드코딩으로 현재 worktree 포트 정책과 불일치
- **수정**: 주석 추가 — "이 값은 root worktree(main 직접 실행) 기준 참고값. 각 agent worktree의 실제 포트는 .env.development.local이 source of truth"

### 커밋 범위
다음 파일 전체를 하나의 커밋으로 묶음 (버그 수정 포함):
