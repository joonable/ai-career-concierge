## 범위

### 대상 파일
- `src/agent/evals/fixtures/job_eval_gold.json` — 대표 샘플 교체 및 expectation 필드 정렬
- `src/agent/evals/rule_based_evaluators.py` — expectation 파싱 로직이 한국어 keyword를 올바르게 처리하는지 점검, 필요 시 조정

### fixture 교체 기준
- `inputs.job.title`, `inputs.job.company`, `inputs.job.jd_raw_text` — 실제 한국 채용 공고 양식으로 교체
- `outputs.expected_strength_keywords`, `outputs.expected_concern_keywords` — JD 텍스트에 실제로 등장하는 한국어 키워드 포함 (소문자 매칭 기준)
- `outputs.scoring_note` — 한국어 서술
- `inputs.user_context.profile_data.role` — 한국어 직함 병행 또는 우선 표기

### 불변 사항
- fixture의 `id` 필드(UUID) 변경 없음 (LangSmith experiment reference 유지)
- fixture JSON 스키마 구조 변경 없음
- evaluator 함수 시그니처 및 반환 타입 변경 없음
- 샘플 수 변경 없음 (내용만 교체)
- LangSmith identifier/tag 변경 없음
