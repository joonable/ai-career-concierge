## 실행 메모

- 실행 위치: 기존 worktree (`../ai-career-concierge-worktrees/codex/unify-worktree-bootstrap-policy`)
- 새 worktree를 만들지 않고 기존 worktree에서 버그 수정 후 커밋
- 작업 순서:
  1. `scripts/worktree_common.sh` 버그 1 (FastAPI 포트) + 버그 2 (api_base_url) 수정
  2. `.claude/launch.json` 주석 추가 (버그 3)
  3. `npm run test -- --run` 실행 후 전체 통과 확인
  4. 미커밋 변경 파일 전체 커밋
  5. PR 생성 → main 머지
- canonical 문서(`TODO.md`, `MILESTONE.md`, `docs/implementation/`)는 루트 저장소에서 별도로 sync-indexes 실행
