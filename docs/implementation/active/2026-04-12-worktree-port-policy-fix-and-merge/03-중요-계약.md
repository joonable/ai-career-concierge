## 중요 계약

- `assign_dev_port(kind, task_slug)` 함수 시그니처 변경 없음 — 호출부 호환성 유지
- FastAPI 포트와 Next.js 포트는 서로 다른 베이스를 사용해 충돌하지 않음을 보장
  - Next.js: codex=3100, claude=3200, gemini=3300, integration=3400
  - FastAPI: codex=8100, claude=8200, gemini=8300, integration=8400
- `api_base_url` 수정 후 생성되는 `NEXT_PUBLIC_API_BASE_URL` 값은 항상 유효한 `http://localhost:<port>` URL이어야 함
- `.claude/launch.json`은 root worktree 참고용으로 유지; 각 agent worktree의 포트는 `.env.development.local`이 source of truth
- PR 머지 전 `python3 scripts/implementation_docs.py validate` 통과
- 브랜치에서 직접 main 수정 없음 — PR을 통해서만 머지
