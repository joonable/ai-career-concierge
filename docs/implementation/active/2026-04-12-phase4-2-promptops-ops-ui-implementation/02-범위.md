## 범위

### 1. `/internal/prompts` UI 정보구조 재설계
- **파일**: `apps/web/src/app/internal/prompts/page.tsx`
- 섹션 구조를 다음 4개 영역으로 재구성:
  1. **현재 상태** — production/staging/candidate lineage, latest decision
  2. **실험/비교 추적** — compare 링크, review queue 링크 (실험 판단 동선)
  3. **후속 액션 추적** — backlog 링크, latest iteration (운영 액션 동선)
  4. **Golden Dataset 기준** — local fixture snapshot read-only 노출
- 각 섹션에 한국어 운영 목적 설명 추가
- 빈 href 방어 로직 유지 (기존 테스트 대상)

### 2. Golden Dataset 로더
- **파일**: `apps/web/src/lib/` 아래 신규 또는 기존 파일에 추가
- 로더 방식: Next.js 서버 컴포넌트에서 `fs/promises` + `path.resolve(process.cwd(), ...)` 로 `job_eval_gold.json` 로드
- 참고 패턴: `apps/web/src/lib/internal_docs.ts`의 `loadPromptOpsDocumentSummary` 함수 (동일한 파일 읽기 방식)
- 추출 필드: `metadata.scenario_type`, `inputs.job.title`, `inputs.job.company`, `outputs.should_pass`, `outputs.fit_score_range`, `metadata.difficulty`
- 실패 시 graceful fallback: 빈 배열 반환, UI는 안내 메시지로 처리

### 3. 테스트 갱신
- `apps/web/src/app/internal/prompts/page.test.tsx` — 4개 섹션 렌더 확인, golden dataset 섹션 확인
- 신규 로더 단위 테스트: 정상 로드, 파일 없음 fallback, JSON 파싱 오류 fallback
- 기존 테스트 전체 통과 유지

### 범위 외
- golden dataset 편집 UI 없음 (read-only만)
- API 서버를 통한 golden dataset 서빙 없음
