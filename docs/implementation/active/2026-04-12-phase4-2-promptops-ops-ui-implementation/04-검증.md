- 4개 섹션(현재 상태, 실험/비교 추적, 후속 액션 추적, Golden Dataset 기준)의 섹션 제목이 DOM에 존재하는지 확인
- golden dataset 샘플 목록 렌더 확인 (시나리오 유형, JD 제목, pass/fail 기대값)
- golden dataset 로드 실패 시 fallback 메시지가 렌더되고 나머지 섹션은 정상 렌더되는지 확인

- `npm run test -- --run` (apps/web) 전체 통과
- 빈 href 방어 테스트 유지 (링크 비활성화 동작)
