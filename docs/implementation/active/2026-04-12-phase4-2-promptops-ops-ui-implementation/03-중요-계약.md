## 중요 계약

- golden dataset source of truth는 Git-tracked local JSON — 웹 화면은 read-only 표시만
- 로더 실패 시 `/internal/prompts` 페이지 전체가 error state가 되면 안 됨 — golden dataset 섹션만 fallback 메시지 표시
- 빈 `href` 값을 가진 링크는 비활성화 처리 (`<Link href="">` 렌더 금지)
- 신규 로더 함수는 서버 컴포넌트 전용 — 클라이언트 컴포넌트에서 import 금지
- `PromptOpsStatusResponse` API 타입 변경이 필요한 경우 백엔드와 동기화 필요. 로컬 파일 로더는 API와 독립적으로 동작
