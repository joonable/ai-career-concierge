# PromptOps metric terminology alignment

목적: 문서와 운영 화면에서 같은 지표를 같은 용어로 읽을 수 있게 terminology를 맞춘다.
- 명확한 산출물: glossary 문서와 UI 라벨 간 용어 정렬 결과
- 이번 세션의 변경 범위: 라벨/표현 보정, glossary와 UI 간 naming alignment
- 사용자가 직접 확인할 검증 방법: 문서와 화면을 나란히 봤을 때 metric 이름과 의미가 일치하는지 확인
- 이번 세션에서 하지 않는 것: 새 metric 추가, 계산 로직 변경, analyze_iteration 구현
