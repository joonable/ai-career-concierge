# PromptOps current metrics UI exposure

목적: 운영 화면에서 현재 사용 중인 지표를 직접 확인할 수 있게 노출한다.
- 명확한 산출물: 현재 metric 목록/값/설명 포인트가 보이는 운영 화면 섹션
- 이번 세션의 변경 범위: 화면 배치, 현재 지표 표시, 최소 설명 라벨링
- 사용자가 직접 확인할 검증 방법: 운영 화면에서 현재 사용 지표가 보이는지 확인
- 이번 세션에서 하지 않는 것: glossary 대규모 문서화, metric 계산 방식 변경, dataset 로더 재작업
