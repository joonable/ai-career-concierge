# Jobkorea fixture pack

목적: Jobkorea 목록/상세 페이지 파싱 작업의 기준이 될 fixture 묶음을 준비한다.
- 명확한 산출물: 테스트 입력으로 재사용 가능한 목록/상세 HTML fixture 세트
- 이번 세션의 변경 범위: fixture 수집, 파일 정리, fixture 용도 설명
- 사용자가 직접 확인할 검증 방법: 테스트 fixture 파일과 샘플 구조를 열어 실제 입력 모양을 확인
- 이번 세션에서 하지 않는 것: 파서 구현, runtime 등록, ingest 연결
