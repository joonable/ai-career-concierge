# PromptOps metric glossary document

목적: 운영자가 현재 평가 지표의 의미와 해석 기준을 문서만 읽고 이해할 수 있게 정리한다.
- 명확한 산출물: 현재 metric 정의와 해석 기준을 담은 glossary 문서 또는 문서 섹션
- 이번 세션의 변경 범위: 지표 정의, 의미, 해석 포인트, 운영 판단 힌트 정리
- 사용자가 직접 확인할 검증 방법: 문서를 읽고 각 metric의 의미와 용도를 바로 이해할 수 있는지 확인
- 이번 세션에서 하지 않는 것: UI 노출, metric 계산 로직 변경, iteration CLI 구현
